# Medical X-ray Interpreter

## Project Overview

Medical X-ray Interpreter is an AI-powered web application developed using Deep Learning (CNN) and Generative AI.

The system automatically classifies chest X-ray images into different diseases and generates simplified medical explanations understandable by non-medical users.

---

## Project Objectives

- Detect diseases from Chest X-rays
- Produce confidence scores
- Generate patient-friendly explanations
- Visualize predictions
- Support image upload
- Explain predictions using Grad-CAM
